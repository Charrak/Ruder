# Markendateien

Alle Dateien sind aus dem gelieferten Logo (`cr=w_1501,h_1500 (1).jpeg`)
abgeleitet, nicht neu gezeichnet.

| Datei | Verwendung |
| --- | --- |
| `logo-mark.png` | Hantel + Pulskurve, dunkelblau – für helle Flächen |
| `logo-mark-light.png` | dieselbe Grafik in Weiß/Signalgrün – für den dunklen Kopfbereich |
| `logo-full.png` | vollständiges Lockup inkl. „physio & fit / VitalZentrum Eschweiler“ |
| `logo-full-light.png` | Lockup in Weiß/Signalgrün |
| `icon.png` | Favicon, transparent |
| `icon-navy.png` | Apple-Touch-Icon, auf Markenblau |

Farben aus dem Logo: Marineblau `#082543`, Signalgrün `#b5e900`.
Die CSS-Variablen `--navy-800` und `--lime` in `src/styles.css` nutzen
exakt diese Werte.

Hinweis: Die Light-Varianten entstanden durch Umfärben der blauen Pixel.
Für Druck oder große Formate ist das Original vorzuziehen.
